# 彩色数据传输系统 - 标准术语定义文档

## 1. 基本显示单元

| 术语 | 定义 | 规格参数 | 功能描述 |
|------|------|----------|----------|
| 色块 | 承载数据的正方形颜色单元 | 20×20 像素（默认）<br>1px 黑色分隔线 | 单个数据块的视觉载体，通过 RGB 颜色值编码 15 位数据（含汉明码） |
| 校准点 | 窗口四角的定位标记 | 40×40 像素<br>四色唯一标识：<br>- 左上：白色 (255,255,255)<br>- 右上：黄色 (255,255,0)<br>- 左下：紫色 (128,0,128)<br>- 右下：青色 (0,255,255) | 提供图像定位基准，辅助摄像头进行透视校正和畸变补偿 |

## 2. 区域定义

| 术语 | 定义 | 尺寸规格 | 坐标范围 |
|------|------|----------|----------|
| 边框 / 校准边框 | 窗口外围的固定宽度功能区域 | 统一宽度 40 像素<br>环绕整个窗口 | 顶部：y=0 至 40，x=0 至 1600<br>底部：y=860 至 900，x=0 至 1600<br>左侧：x=0 至 40，y=0 至 900<br>右侧：x=1560 至 1600，y=0 至 900 |
| 数据区 | 边框内部的有效数据传输区域 | 1520×820 像素<br>(1600-2×40=1520；900-2×40=820) | 左上角：(40, 40)<br>右下角：(1560, 860) |

## 3. 传输相关术语

| 术语 | 定义 | 技术参数 | 备注 |
|------|------|----------|------|
| 页 | 单次显示的完整数据帧 | 包含：1 个数据区 + 完整边框（含 4 个校准点） | 页大小：1600×900 像素<br>数据密度：3116 色块 / 页 |
| 传输速度 | 单位时间内传输的页数 | 单位：FPS（帧 / 秒）或页 /s<br>建议范围：15-30 FPS<br>对应单页显示时长：66.7-33.3ms | 速度与准确率权衡：<br>- 高速（30 FPS）：适合短距离、良好光照<br>- 低速（15 FPS）：适合长距离、复杂环境 |

## 4. 空间布局规范

### 4.1 整体布局

```plaintext
+------------------------------------------------------+
| 左上校准点  顶部边框（40像素）           右上校准点     |
| (40×40)    32个校准色块（40×40）      (40×40)        |
|                                                      |
| 左         数据区（1520×820）          右            |
| 侧         76×41色块矩阵              侧            |
| 边         （20×20像素色块）           边            |
| 框         坐标(40,40)-(1560,860)      框            |
|                                                      |
| 左下校准点  底部边框（40像素）           右下校准点     |
| (40×40)    32个校准色块+状态显示       (40×40)        |
+------------------------------------------------------+
1600px宽度                     900px高度
```

### 4.2 边框详细构成

- **顶部边框（y=0~40）**
  - 左侧：40×40 左上校准点（白色）
  - 中间：32 个 40×40 校准色块（00000-11111）
  - 右侧：40×40 右上校准点（黄色）

- **底部边框（y=860~900）**
  - 左侧：40×40 左下校准点（紫色）
  - 中间：32 个 40×40 校准色块（00000-11111）
  - 右侧区域：
    - 6 个状态显示块（20×40 像素）
    - 40×40 右下校准点（青色）

- **左右边框（x=0~40 和 x=1560~1600）**
  - 顶部：40×40 角校准点
  - 中间：32 个 40×20 校准色块（垂直排列，00000-11111）
  - 底部：9 个 40×20 边框尾块（黑色填充）

### 4.3 数据区色块矩阵

- 排列方式：行列矩阵（76 列 ×41 行）
- 色块容量：76×41=3116 个色块 / 页
- 寻址方式：行优先（从左到右，从上到下）
- 坐标计算：
  第 (i,j) 色块位置：(40 + j×20, 40 + i×20)
  i：行索引（0-40），j：列索引（0-75）
  示例：第 (0,0) 色块位于 (40,40)，第 (0,1) 位于 (60,40)

## 5. 术语使用规范

### 5.1 一致性要求

- 描述显示区域必须使用 "数据区" 而非 "内容区" 或 "有效区"
- 描述完整帧必须使用 "页" 而非 "帧" 或 "画面"
- 边框宽度统一称为 "40 像素" 而非 "40px"（代码中除外）

### 5.2 避免歧义

- "校准边框" 特指 40 像素功能边框，与普通装饰边框区分
- "传输速度" 专指页 /s，与系统响应速度区分
- "色块" 仅指数据区的 20×20 数据单元，边框中的颜色块称为 "校准色块"

### 5.3 单位规范

- 长度单位：像素（非 px）
- 速度单位：页 /s 或 FPS（非 fps）
- 颜色值：十进制 RGB 三元组（如 (65,65,65) 而非 #414141）

> 注：四个角的校准点包含在校准边框内。
