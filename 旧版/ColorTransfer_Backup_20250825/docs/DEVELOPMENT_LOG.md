# 颜色传输系统开发日志

## 项目概述
本项目实现了一个基于颜色映射的视觉数据传输系统，包括发送端(sender)和接收端(receiver)两个主要模块，通过配置文件(config.json)进行参数管理，并使用机器学习模型进行颜色预测。

## 模块功能说明

### 1. sender.py
- **主要功能**：将二进制数据编码为RGB颜色值，并生成包含这些颜色的图像帧
- **核心函数**：
  - `__init__`: 初始化发送器，加载配置参数
  - `data_to_color`: 将15位二进制数据映射为RGB颜色值（每个通道5位）
  - `create_data_frame`: 创建包含数据色块的图像帧
  - `send_data`: 发送数据的主流程
- **颜色映射算法**：实现了分段线性映射
  - 低段(0-15)：间隔8，映射到65-185
  - 高段(16-31)：间隔5，映射到190-255

### 2. receiver.py
- **主要功能**：从摄像头捕获图像，检测同步图案，提取颜色块，并解码为二进制数据
- **核心函数**：
  - `__init__`: 初始化接收器，加载配置参数和模型
  - `capture_frame`: 捕获摄像头图像
  - `detect_sync_pattern`: 检测同步图案
  - `calculate_perspective_transform`: 计算透视变换矩阵
  - `apply_perspective_transform`: 应用透视变换进行校准
  - `extract_color_blocks`: 提取颜色块（包括校准色块和数据色块）
  - `decode_data`: 解码颜色数据为二进制
  - `receive_data`: 接收数据的主流程

### 3. model/predict.py
- **主要功能**：实现颜色预测模型的推理接口
- **核心类/函数**：
  - `ColorPredictor`: 颜色预测器类
    - `__init__`: 初始化预测器，加载模型
    - `preprocess`: 预处理输入数据
    - `predict`: 执行预测，返回15位二进制数据
  - 主函数：提供测试功能

### 4. config.json
- **主要功能**：存储系统配置参数
- **核心配置块**：
  - `training`: 模型训练相关参数
  - `hardware`: 硬件相关参数
  - `color_mapping`: 颜色映射参数（分段线性映射的阈值和步长）
  - `calibration`: 校准相关参数（边框宽度、校准点数量等）

## 模块间函数调用关系

### 发送流程
1. `sender.send_data` -> `sender.create_data_frame`
2. `sender.create_data_frame` -> `sender.data_to_color`
3. `sender.data_to_color` 使用 `config.json` 中的颜色映射参数

### 接收流程
1. `receiver.receive_data` -> `receiver.capture_frame`
2. `receiver.receive_data` -> `receiver.detect_sync_pattern`
3. `receiver.receive_data` -> `receiver.calculate_perspective_transform`
4. `receiver.receive_data` -> `receiver.apply_perspective_transform`
5. `receiver.receive_data` -> `receiver.extract_color_blocks`
6. `receiver.receive_data` -> `receiver.decode_data`
7. `receiver.decode_data` 使用 `model.predict.ColorPredictor.predict` 进行颜色预测
8. 所有函数使用 `config.json` 中的配置参数
