# 彩色数据传输系统 - 开发日志记录程序使用指南

这个工具帮助开发者轻松记录开发过程，自动生成详细的开发日志。支持日志记录在同一文件中，方便阅读和追踪，还能根据项目计划和已完成进度自动生成今日任务。本指南将介绍如何使用这个工具。

## 1. 记录条目设计

程序会自动生成包含以下条目的开发日志：

| 条目 | 说明 | 示例 |
|------|------|------|
| 日期时间 | 自动记录开发开始和结束时间 | 2023-11-15 14:30-16:45 |
| 当日任务 | 简洁描述当天的开发任务 | 实现发送端边框绘制功能 |
| 完成进度 | 任务完成百分比和具体成果 | 80%（完成底部和顶部边框） |
| 开发耗时 | 自动计算开发用时 | 2小时15分钟 |
| 关键代码 | 记录核心实现代码 | 绘制边框的函数 |
| 遇到的问题 | 分类记录开发中的问题 | 颜色值计算错误（逻辑错误） |
| 调试步骤 | 分步骤记录调试过程 | 打印变量→发现通道值不相等→修正公式 |
| 解决方案 | 详细描述问题解决方案 | 将r/g/b值设为相同实现灰度 |
| 测试结果 | 可量化的测试结果 | 32个色块从65渐变到189 |
| 截图位置 | 提示插入相关截图 | [边框测试截图.png] |
| 明日计划 | 最多3项第二天的计划 | 实现左右边框绘制 |
| 学习心得 | 1-2句话总结学习收获 | 学会使用OpenCV的rectangle函数 |

## 2. 程序参数说明

| 参数 | 说明 | 示例 | 必填 |
|------|------|------|------|
| --start | 开始记录开发时间 | `python development_logger.py --start` | 否 |
| --end | 结束记录并生成日志 | `python development_logger.py --end` | 否 |
| --task | 当日任务描述 | `--task "实现边框绘制功能"` | 是（与--end一起使用） |
| --done | 已完成事项（逗号分隔） | `--done "底部边框,顶部边框"` | 否 |
| --issue | 遇到的问题 | `--issue "颜色值计算错误"` | 否 |
| --fixed | 解决方案 | `--fixed "将r/g/b值设为相同"` | 否 |
| --test | 测试结果 | `--test "32个色块显示正常"` | 否 |
| --next | 明日计划（逗号分隔） | `--next "实现左右边框,添加状态显示"` | 否 |
| --progress | 完成进度（0-100） | `--progress 80` | 否 |
| --code | 关键代码文件路径 | `--code ./sender/draw_border.py` | 否 |
| --screenshot | 截图文件路径 | `--screenshot ./test_border.png` | 否 |
| --note | 学习心得 | `--note "学会使用OpenCV的rectangle函数"` | 否 |
| --module | 所属模块 | `--module "发送端开发"` | 否 |

## 3. 自动化功能说明

1. **时间管理**：自动记录开始/结束时间，计算开发耗时
2. **进度跟踪**：累计项目总耗时，按模块统计完成百分比
3. **错误分类**：自动分类错误类型（语法/逻辑/环境错误等）
4. **周报告**：每周日自动生成周进度报告（表格形式）
5. **模板填充**：自动生成日志格式，只需填写关键内容
6. **数据备份**：自动备份日志文件，防止意外丢失
7. **鼓励机制**：完成80%以上进度时显示鼓励语句
8. **自动任务生成**：根据项目计划和已完成进度自动生成今日任务（无需手动指定--task参数）

## 4. 使用步骤

### 步骤1: 开始记录开发时间

打开命令提示符或PowerShell，进入项目目录，执行以下命令开始记录开发时间：

```bash
python development_logger.py --start
```

程序会显示开始时间，并提示你开始开发工作。

### 步骤2: 完成开发工作

进行你的开发工作，例如编写代码、测试功能等。

### 步骤3: 结束记录并生成日志

当你完成当天的开发工作后，执行以下命令结束记录并生成日志：

#### 方式1: 手动指定任务
```bash
python development_logger.py --end --task "实现发送端边框绘制功能" --done "底部边框,顶部边框" --issue "颜色值计算错误" --fixed "将r/g/b值设为相同" --test "32个色块显示正常" --next "实现左右边框,添加状态显示" --progress 80 --note "学会使用OpenCV的rectangle函数" --module "发送端开发"
```

#### 方式2: 自动生成任务
```bash
python development_logger.py --end
```

程序会根据项目计划和已完成进度自动生成今日任务，并提示你确认。

### 步骤4: 查看生成的日志

日志文件会保存在`docs/DEVELOPMENT_LOG.md`文件中，所有日志记录都会追加到这个文件中。

## 5. 使用示例

### 示例1: 基本使用（手动指定任务）

```bash
# 开始记录
python development_logger.py --start

# 结束记录并生成日志
python development_logger.py --end --task "实现边框绘制" --done "底部边框,顶部边框" --progress 80
```

### 示例2: 使用自动生成任务功能

```bash
# 开始记录
python development_logger.py --start

# 结束记录并让程序自动生成任务
python development_logger.py --end
```

执行后，程序会显示自动生成的任务列表，你可以选择其中一个或输入自己的任务。

### 示例3: 记录问题和解决方案

```bash
python development_logger.py --end --task "调试颜色映射功能" --issue "颜色显示异常" --fixed "调整RGB通道映射公式" --test "16个色块颜色准确" --module "发送端开发"
```

### 示例4: 包含代码片段

```bash
python development_logger.py --end --task "实现数据编码函数" --done "汉明码编码" --code ./core/encoder.py --progress 90 --note "学习了汉明码纠错原理"
```

## 7. 注意事项

1. 结束记录时，`--task`参数不再是必填项，程序可以自动生成今日任务
2. 进度值必须在0-100之间
3. 日志文件会自动保存在`docs/DEVELOPMENT_LOG.md`文件中
4. 每周日会自动生成周进度报告
5. 如果需要修改日志，可以直接编辑`docs/DEVELOPMENT_LOG.md`文件
6. 程序会自动备份已存在的日志文件，防止数据丢失
7. 自动生成任务功能依赖于`docs/DEVELOPMENT_PLAN.md`文件中的项目计划
8. 如果项目计划文件不存在或格式不正确，程序会提供默认任务建议

希望这个工具能帮助你更好地记录和管理开发过程！
