# ColorTransfer / opti-link 术语规范

> 版本 v1.0 ｜ 2026-09-07
> 本项目所有交流（人/文档/代码注释）一律遵守本规范。
> 目的：消除"格子""块""校准""颜色数"等高频歧义，这些歧义已在前期造成过实际的错误结论。

---

## 0. 三条铁律（违反者一律要求重写）

**铁律 1 — 空间层级必须唯一**
任何"格 / 块 / 单元 / 子格"必须带限定词，禁止单独使用。
本项目有严格四级：`帧 → 数据格 → 符号 → 符号像素`。

**铁律 2 — 数值必须带单位与换算**
- 颜色位宽必须写成 `2 bit (4色)` 格式，禁止只写"4色"或"2bit"造成歧义。
- 长度必须标注参照系：`屏幕像素` / `摄像头像素` / `毫米`，三者不可混用。

**铁律 3 — 标定 ≠ 校正**
这是本项目最容易混淆、也最致命的一对词：

| 词 | 英文 | 时机 | 干什么 |
|---|---|---|---|
| **标定** | calibration | 离线、一次性 | 用真机测出信道参数，产出 `calibration.json` |
| **校正** | correction | 在线、每帧 | 用校准格修正拍摄到的图像 |

**校准格属于"校正"机制，不叫"标定格"。** 三组实测数据叫"标定数据"，不叫"校准数据"。

## 1. 空间层级（自上而下，禁止跳级混用）

| 层级 | 中文术语 | 英文 | 定义 |
|---|---|---|---|
| L0 | **帧** | frame | 一屏完整图像，含锚点+校准格+数据格 |
| L1 | **数据格** | cell | 承载数据的基本单元，边长 `cellPx` 个**屏幕像素** |
| L1′ | **校准格** | pilot cell | 颜色已知的参考格，**不承载数据** |
| L1″ | **锚点** | anchor / fiducial | 用于定位与透视校正的标记 |
| L2 | **符号** | symbol | 数据格内部的形状图案（当前 16 种） |
| L3 | **符号像素** | symbol pixel | 符号图案内部的像素（如 8×8） |

**禁止**：用"格子""块""单元"单独指代任何一级。

---

## 2. 编码与调制

| 术语 | 英文 | 定义 |
|---|---|---|
| **形状维度** | symbol/shape bits | 靠符号图案携带的 bit，抗模糊主力 |
| **颜色维度** | color bits | 靠数据格底色携带的 bit，密度高但脆弱 |
| **符号集** | symbol alphabet | 16 个符号图案的集合，离线寻优生成 |
| **最小汉明距离** | minDist | 符号集中两两图案的最小差异，当前 = **29** |
| **调制** | modulation | 把 bit 映射到 (符号, 颜色) 的过程 |

### 位宽 ↔ 色数换算（强制对照）

| 位宽 | 色数 | 书写格式（必须用这种） |
|---|---|---|
| 1 bit | 2 色 | `1 bit (2色)` |
| 2 bit | 4 色 | `2 bit (4色)` |
| 3 bit | 8 色 | `3 bit (8色)` |
| 4 bit | 16 色 | `4 bit (16色)` |
| 5 bit | 32 色 | `5 bit (32色)` |
| 6 bit | 64 色 | `6 bit (64色)` |
| 7 bit | 128 色 | `7 bit (128色)` |

**`colorBits = 0` 表示无颜色维度（形状 only），此时色数 = 1（单色底）。**

## 3. 档位（三档，人工选，发送后锁定）

| 档位 | cellPx | 默认颜色 | 校准模式 | 依据 |
|---|---|---|---|---|
| **safe** | 13 | `2 bit (4色)` | 四角 | `web_auto` 最差包络，擂台赛 M1 |
| **balanced** | **8** | 待定 | 密集 | 擂台赛 M3（成功率 0.9999） |
| **fast** | 5 | 待定 | — | `native` 原生相机 |

> ⚠️ balanced 的 cellPx 统一为 **8**（不是 7）。7 从未测过，不引入未验证参数。

**运行时不变**：一帧开始编码后，档位在整个文件传输期间不得更改。

## 4. 信道参数（标定所得，入 `calibration.json`）

| 符号 | 术语 | 定义 | 单位 |
|---|---|---|---|
| **ρ** | 采样率比 | 摄像头像素 / 屏幕像素 | 无量纲 |
| **σ_PSF** | 模糊核标准差 | 失焦+运动的综合模糊 | **屏幕像素** |
| **γ** | 伽马 | 屏幕→相机的灰度响应指数 | 无量纲 |
| **CCM** | 色彩串扰矩阵 | 3×3 颜色变换 | — |
| — | 非径向亮度梯度 | 四角实测亮度，**径向暗角模型在此设备失效** | 归一化 0~1 |
| **σ_Y** | 亮度噪声 | 平坦区噪声标准差 | 灰度级 |
| **SNR** | 信噪比 | — | dB |
| **d_min** | 最小可行单元 | 理论最小单元边长 | **屏幕像素** |
| **d_rec** | 建议单元边长 | 实际采用值 | **屏幕像素** |

### 四角亮度实测值（下方明显更亮）
`tl 0.252 / tr 0.201 / bl 0.493 / br 0.428`（中心 0.289）

## 5. 光学损伤（仿真器必须建模）

| 术语 | 英文 | 关键特性 |
|---|---|---|
| **模糊** | blur | 失焦（高斯 PSF）+ 手抖（运动模糊） |
| **摩尔纹** | moiré | **空间频率混叠**，非加性噪声，对几何位置极度敏感 |
| **卷帘快门** | rolling shutter | 行方向时间偏移导致斜切 |
| **反光 / 眩光** | glare | 局部区域整体抬高，常毁掉一片数据格 |
| **色度子采样** | chroma subsampling | 4:2:0，色彩分辨率仅亮度的 1/4 |

**摩尔纹校准后的颜色上限**（多帧时间平均可再提升）：

| 条件 | 单帧 | 多帧 ×8 |
|---|---|---|
| `web_auto`（最差） | `3 bit (8色)` | `5 bit (32色)` |
| `native`（最好） | `4 bit (16色)` | — |
| `web_locked` | `7 bit (128色)` | — |

## 6. 纠错层次（由外到内）

| 层 | 技术 | 解决什么 |
|---|---|---|
| 外层 | **LT 喷泉码** | 块级擦除、乱序、丢帧；收够任意 N+1 个即可还原 |
| 内层 | **RS(255,223)** | 块内比特错误 |
| 可选 | **交织** | 打散空间聚簇错误，**仅在实测聚簇严重时启用** |

**禁止使用汉明码**——它只抗随机单比特错，与本信道的突发聚簇错误类型不匹配。

### 数据块 / 数据格 / 编码包（三者严禁混用）

| 术语 | 英文 | 所在层 |
|---|---|---|
| **数据块** | block | RS/LT 层，几百字节 |
| **编码包** | droplet | LT 生成的混合包 |
| **数据格** | cell | 屏幕层，一个格子 |

## 7. 性能指标（必须区分，禁止混称）

| 指标 | 英文 | 定义 |
|---|---|---|
| **格错误率** | cell error rate | 判错的**数据格**占比 |
| **比特错误率** | BER | 判错的**比特**占比 |
| **解码成功率** | success rate | 整帧/整文件完全还原的比例 |
| **净吞吐** | net throughput | `bit/数据格`，**已扣除校准格开销** |
| **有效速率** | effective rate | 端到端 `KB/s` 或 `Mbps` |

> ⚠️ 报告里说"BER"时必须注明是格错误率还是比特错误率，二者数值不同。

当前最优：M1 = **5.98 bit/格**，解码成功率 1.0。

## 8. 接收端管线（固定四阶段）

```
locate 定位  →  normalize 归一化  →  decoder 解码  →  reassemble 重组
```

| 阶段 | 干什么 | 必须处理 |
|---|---|---|
| **locate** | 找锚点、算透视矩阵 | 完整性校验，各向异性超阈值**显式报错** |
| **normalize** | 拉正、旋转自适应、亮度校正 | 躺倒竖图（`3072×4096`）、非径向梯度 |
| **decoder** | 逐数据格判符号+颜色 | 符号汉明匹配、颜色相对匹配 |
| **reassemble** | LT 重组 + RS 纠错 | 收够即停 |

| ❌ 禁止 | ✅ 必须写成 |

| "格子" | 数据格 / 校准格 / 锚点（指明是哪一级） |
| "块" | 数据块 / 编码包 / 数据格（指明是哪一层） |

| "成功率 100%" | 解码成功率 1.0（整文件还原） |

## 12. 代码命名规范

| 对象 | 规范 | 示例 |
|---|---|---|
| 变量/函数 | camelCase | `encodeCell`, `pilotSpacing` |
| 类型/组件 | PascalCase | `ColorBits`, `SendPage` |

**注释规则**：注释解释「为什么」，不解释「做了什么」。设计参数必须给出推导或实测依据。

## 13. 已知假设（真机实测前需校准）

- 屏幕 PPI = **96**（假设，待实测）
- 局部高频波纹 ±8~13%（实测仅四角分辨率，精度有限）
- 校准格采样无噪声（仿真器内为理想真值，**真机残余会更高**）
- 符号集 minDist = 29（模糊前）
