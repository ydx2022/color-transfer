==== 3. 铁律（不可推翻，除非实测反证）====
- ECC 一律 RS + 喷泉（LT 外层 + RS(255,223) 内层）；禁止汉明码。
- 每模块 encode→decode bit-exact round-trip 测试。
- 仿真器只读实测 calibration.json，禁止凭空假设。
- 档位人工选档、发送后锁定：safe=13 / balanced=7 / fast=5。
- 音频反馈本期暂缓（喷泉收够即停，ARQ 价值被削弱），仅预留 flag。
- 符号集最小汉明距离由实测决定，不预设 20bit（当前离线寻优得 29）。

==== 4. 三组实测标定（已落入仿真器）====
- 原生相机 / 华为 Mate50E：σ_PSF=0.52，d_rec=3（上限）
- 网页锁定 / Android+Edge：σ_PSF=1.03，d_rec=5（典型）
- 网页自动 / 华为浏览器：σ_PSF=2.78，d_rec=13（最差包络，safe 档依据）
关键事实：存在非径向亮度梯度（四角 0.25/0.20/0.49/0.43，下方更亮），径向暗角模型失效 → 必须局部归一化/密集校准。

==== 5. 调制擂台赛（信道 = web_auto 最差包络）====
净吞吐 = 每格 bits × (1 − 校准格开销)；RS 额外块级开销因子 0.8745。
- M1：cellPx=13，符号4bit+颜色2bit，四角校准，格错误率 0.0000，净吞吐 5.98，成功率 1.0000（推荐 safe）
- M2：cellPx=13，符号4bit+颜色0bit，无校准，0.9292，4.00，0.0000
- M3：cellPx=8，符号4bit+颜色1bit，密集校准，0.0236，4.42，0.9999（双色稳健主力候选）
- M4：cellPx=6，符号2bit+颜色1bit，密集校准，0.1519，2.65，0.0000
- M5：cellPx=5，符号4bit+颜色0bit，无校准，0.9225，4.00，0.0000
- M6：cellPx=3，符号0bit+颜色1bit，密集校准，dead，0.88，1.0000
- M7a：cellPx=13，符号0bit+颜色2bit，密集校准，0.0000，1.77，1.0000
- M7b：cellPx=13，符号0bit+颜色3bit，密集校准，0.0000，2.65，1.0000
- M7c：cellPx=13，符号0bit+颜色4bit，密集校准，0.0085，3.53，1.0000
推荐 safe = M1（4bit+2色+四角校准，吞吐最高且成功率 1.0）；M3 为双色稳健主力候选（成功率 0.9999）。

==== 6. 密集校准有效性（用户核心关切：纯颜色 M7）====
- M7a（2色）：无校准格错误率 0.2417 → 密集校准后 0.0000（完全消除）
- M7b（3色）：无校准 0.5450 → 密集校准后 0.0000（完全消除）
- M7c（4色）：无校准 0.8275 → 密集校准后 0.0085（97.5× 改善）
⚠ 模型假设：仿真器中校准格采样读同一梯度场真值，故校正接近完全消除；真实设备有采样噪声与空间错位，实测残余更高。此处验证的是「密集校准机制原理上可消除梯度」这一命题。
